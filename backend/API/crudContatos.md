## Rotas da API – CRUD de Contatos

| Método | URL                      | Descrição |
|--------|--------------------------|-----------|
| GET    | /contatos/alunos         | Listar contatos |
| POST   | /contatos/alunos         | Criar contato |
| PUT    | /contatos/alunos/0       | Atualizar contato |
| DELETE | /contatos/alunos/0       | Excluir contato |
