# Projeto PHP - Empresa Fictícia

## Descrição
Página desenvolvida em PHP exibindo informações de uma empresa fictícia.

## Empresa escolhida
Sport Clube Corinthians Paulista

## Dados exibidos
- Nome da empresa
- Ano de fundação
- Quantidade de funcionários
- Faturamento
- Status da empresa

## Tecnologias utilizadas
- PHP
- HTML
- CSS

## Como executar
1. Salve o arquivo como `index.php`
2. Coloque em um servidor local (XAMPP, WAMP ou Laragon)
3. Abra no navegador
