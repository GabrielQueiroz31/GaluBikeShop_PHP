# S5_R1_AT1

## Descrição
Projeto em PHP desenvolvido para praticar estruturas condicionais (`if`, `elseif`, `else`) e estrutura de seleção (`switch case`).

A página exibe informações de uma empresa fictícia de acordo com dados definidos no código.

## Funcionalidades

- Classifica o porte da empresa pela quantidade de funcionários.
- Informa se a empresa é nova no mercado ou consolidada.
- Exibe o setor escolhido.

## Tecnologias Utilizadas

- PHP
- HTML5

## Estrutura do Código

### Variáveis utilizadas:

- `$funcionarios` → quantidade de funcionários.
- `$tempo` → tempo de mercado da empresa.
- `$setor` → setor da empresa.

### Condições aplicadas:

- `if / elseif / else`
- `switch case`

## Resultado Esperado

Exemplo exibido no navegador:

Empresa Ficticia

Empresa de Grande porte

Empresa consolidada

Setor de Tec

## Como Executar

1. Salve o arquivo como `index.php`
2. Coloque em um servidor local (XAMPP, WAMP ou Laragon)
3. Abra no navegador:

http://localhost/index.php
